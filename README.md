# Lemon Studio Plugins

The plugins from [Lemon Studio](https://github.com/ItsAlphaNeon/Lemon-Studio) by ItsAlphaNeon and its contributors, built as VST3 and CLAP for Windows and Linux (64-bit). These are unofficial builds, made from Lemon Studio's source at commit `556481e6`.

Download them from the [Releases page](../../releases). Each zip has an `INSTALL.txt` with the steps.

## Plugins

- **Instruments and samplers:** Lemon Sampler, Lemon Trio, Citrus, Lemon Drum Sampler, Lemon Slicer
- **Effects:** Lemon Parametric EQ, Lemon Limiter, Lemon Reverb, Lemon Delay, Lemon Soft Clipper, Lemon Fast Distortion, Lemon Balance, Lemon Stereo Enhancer, Lemon Stereo Shaper, Lemon Transient Processor, Lemon Chorus, Lemon Filter, Lemon Flanger, Lemon Phaser, Lemon Vocoder, Press, Pulp Filter, Tesla
- **Controllers:** Lemon Peak Controller, Lemon Formula Controller

## Status

- **Windows:** built with MinGW and not yet tested on a real Windows PC or in a Windows DAW. They aren't signed, so Windows may warn about them.
- **Linux:** built against glibc 2.43, so they need a very recent Linux distribution.
